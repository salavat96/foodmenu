# Foodmenu Bot

Telegram-бот с пошаговыми рецептами и генерацией меню на период с учётом бюджета,
аллергий, нелюбимых продуктов и типа диеты. Подробный план разработки — в
[docs/PLAN.md](docs/PLAN.md).

## Возможности

- 🍳 Пошаговый показ рецепта (ингредиенты → шаги с навигацией «Далее/Назад»).
- 📅 Генерация меню на 7/14 дней с учётом бюджета, аллергий и нелюбимых продуктов;
  расписание завтрак/обед/ужин.
- ⏰ Напоминания о приёме пищи в настраиваемое пользователем время.
- ⚖️ Меню для похудения / под конкретный тип диеты (кето, низкоуглеводная,
  вегетарианская, веганская, высокобелковая, средиземноморская).
- 🛡 Фильтр нетематических сообщений и защита от флуда.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt

cp .env.example .env
# впиши в .env свой BOT_TOKEN, полученный у @BotFather

python -m app.main
```

По умолчанию используется локальная SQLite-база (`foodmenu.db`), создаётся
автоматически при первом запуске вместе с демо-набором рецептов.

## Запуск в Docker

```bash
cp .env.example .env
docker compose up --build -d
```

## Тесты

```bash
pytest
```

## Структура проекта

```
app/
  config.py          # настройки из .env
  main.py            # точка входа
  database/          # модели SQLAlchemy, сессия, репозиторий
  data/               # сид-данные рецептов
  handlers/          # хендлеры aiogram (старт, рецепты, меню, настройки)
  keyboards/         # инлайн-клавиатуры
  middlewares/       # антиспам/off-topic фильтр
  services/          # бизнес-логика (рецепты, генерация меню, напоминания)
docs/PLAN.md          # план разработки на 2 недели
```
